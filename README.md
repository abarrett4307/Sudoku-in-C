Sudoku in C

Authors:
- Justin Li
- Abigail Yun
- Tony Barrett
- Paulene Mendoza Morrison
- Nicholas Chamaki

Course: CS2600

Description:
  This program implements a Sudoku game in C using dynamic memory. It creates a 9x9 board and loads a default puzzle from a file, allowing the user to enter moves. It also prevents any invalid moves, enforcing the rules of Sudoku. Any value of 0 represents a blank space on the board. The user will enter any value from 1-8 to specify which row and coluimnn, and any value from 1-9 as the input value. The game will end once the board is completely filled or if the user chooses to quit.
